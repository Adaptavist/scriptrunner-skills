The Web App has three main points of navigation:

-   [Navigate to features](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/web-app-navigation#navigate-to-features--en)
-   [Navigate to support tools and resources](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/web-app-navigation#concept-3355--en)
-   [Navigate to settings](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/web-app-navigation#navigate-to-settings--en)

## Navigate to features

You can find the main feature navigation on the left-hand side of the Web App:

Using these, you can navigate to:

-   The Home screen
-   The new [Projects](projects.md) feature
-   The [Analyse and Assess Tool](script-runner-migration-analyse-and-assess-tool.md)
-   The [Migration Agent](script-runner-migration-agent.md)
-   The [Dev and Deployment Tool documentation](../uncategorized/s/script-runner-dev-and-deployment-tool.md)

## Navigate to support tools and resources

Use the bottom left-hand navigation to find support tools and resources:

-   Select Help and Resources to select the following resources:
    -   Raise support ticket: Sends you to [the support portal](https://the-adaptavist-group-support.atlassian.net/servicedesk/customer/portal/1069/user/login?destination=portal%2F1069).
    -   Training: Sends you to the [Training](../uncategorized/t/training.md) module of the documentation.
    -   Documentation: Sends you to the product [documentation](../uncategorized/s/script-runner-migration-suite-web-app.md).
    -   Feedback: Navigates you to a [feedback](https://docs.google.com/forms/d/e/1FAIpQLSeo-YAZ2tma3LxsuDFsTgSFjj_WpnqcUiWqsHFPCIVFUgHs4Q/viewform) form.
-   Select Terms of Service to load the _ScriptRunner Migration Suite Terms of Service_.

## Navigate to settings

To navigate to settings, select next to your username:

From there, you can:

-   View and create [API Keys](api-keys.md)
-   [Import Chats](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/migrate-from-version-1-to-version-2#import-chats-in-version-2--en) from version 1 of the ScriptRunner Migration Suite
-   Change the Theme to _Light_, _Dark_, and _System_
-   Review Cookie Preferences
-   Switch Region (learn more about this in [Data Residency and Privacy](data-residency-and-privacy.md))
-   Log out
