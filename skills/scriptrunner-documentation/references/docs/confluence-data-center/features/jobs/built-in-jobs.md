# Built-In Jobs

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Features > Jobs
- Doc ID: doc-sr4c-d1d29702-760d-4aa6-b48a-f2a5f5917143-5f5e6f8daf0a3a05
- Source: https://docs.adaptavist.com/sr4c/latest/features#jobs--en#built-in-jobs--en

Built-in jobs are available for you to use when you install ScriptRunner for Confluence.

To use one of these jobs, follow these steps:

1.  Navigate to Confluence Administration by selecting the Cog button and then selecting General Configuration.
2.  In the left menu bar, under _ScriptRunner_, navigate to Jobs.
3.  Select Create a Job.
    
    Note: If you're unsure about how to get started, consider clicking the Add Examples button and select from a list of pre-configured examples. If you choose to add example(s), they will be disabled by default until you enable them.
    
4.  Select one of the following built-in jobs:
    
    -   [Bulk Delete Attachments Job](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/bulk-delete-attachments-job)
    -   [Bulk Purge Trash Job](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/bulk-purge-trash-job)
    -   [CQL Escalation Services](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/cql-escalation-services)
    -   [Manage Labels Job](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/manage-labels-job)
    -   [Old Content Notifier Job](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/old-content-notifier-job)
    -   [Prune Old Versions Job](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/prune-old-versions-job)
    -   [Update Page Restrictions Job](https://docs.adaptavist.com/sr4c/latest/features/jobs/built-in-jobs/update-page-restrictions-job)
    
5.  Fill out the form that appears.
    
    Tip: For help with the form, follow the link that corresponds with the job from the above step.
    
6.  Save the job.
