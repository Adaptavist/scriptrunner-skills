# Script Failure Notifications

- Platform: connect
- Space: SRC
- Hierarchy: observability
- Doc ID: doc-src-465437008
- Source: https://docs.adaptavist.com/src/latest/observability/script-failure-notifications

Script failure constitutes an uncaught error on the script level, a thrown object which is allowed to propagate beyond the entry function of the script.

To receive real-time notifications for scripts that fail in your workspaces, you can enable email notifications. To do that:

1.   Go to **Profile settings.**
2.  In the _Email notifications_ section, enable the **workspace script failures** toggle option.

You will now receive email notifications for all workspaces to which you have access. 

## Customize notifications on the workspace level

To disable receiving notifications from some workspaces:

1.  Click the **three-dot menu** on the _workspace header._
2.  Then select **Email Notifications.**
3.  From here, you can select which environment you wish to receive notifications from.  
    To disable notifications for the entire workspace, unselect all environments.
