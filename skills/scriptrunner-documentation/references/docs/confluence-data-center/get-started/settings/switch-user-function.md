# Switch User Function

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Get Started > Settings
- Doc ID: doc-sr4c-4cd31c8e-3e75-478c-aa15-0ea284e3f6e9-8521230eea182fbb
- Source: https://docs.adaptavist.com/sr4c/latest/get-started#settings--en#switch-user-function--en

The Switch User function allows administrator users to temporarily assume another user's identity.

You can switch users through the [Switch User](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/confluence-administration-built-in-scripts/switch-to-a-different-user) built-in script. This script is enabled by default. However, if you have extremely strong compliance requirements, you may wish to disable this feature.

Note: Users with Script Edit Permissions can still create scripts that perform a user switch via the API.

## How to enable/disable

To enable or disable _Switch User_ follow the steps below:

1.  From ScriptRunner, select Settings.
    
2.  Toggle the _Switch to a Different User_ option to on or off.
    

## How to switch user in Confluence

With ScriptRunner, an administrator can easily switch user to assume the identity of another temporarily by using the [Switch to a Different User](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/confluence-administration-built-in-scripts/switch-to-a-different-user) built-in script.

## Switch back to original user

To switch back to your original user, click the Return to session as \[your name\] link in the _Switch User_ banner, or log out and in again.
