# Automation for Jira

- Platform: data-center
- Space: SR4JS
- Hierarchy: integrations
- Doc ID: doc-sr4js-442888386
- Source: https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira

We have developed actions and triggers you can use in [Automation for Jira](https://marketplace.atlassian.com/plugins/com.codebarrel.addons.automation/server/overview):

###### [Asset Object Created Trigger](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/asset-object-created-trigger)

Use this trigger to create a rule that runs whenever an Assets object is created.

###### [Asset Object Updated Trigger](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/asset-object-updated-trigger)

Use this trigger to create a rule that runs whenever an Assets object is updated.

###### [Create Asset](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/create-asset)

Use this action to create an Assets (Insight) object. 

###### [Execute a ScriptRunner Script](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/execute-a-scriptrunner-script)

Use this action to run a ScriptRunner script, either inline or from a file. 

###### [Lookup Asset (Insight) Object](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/lookup-asset-insight-object)

Use this action to look up an Asset (Insight) object and include the result in other actions. 

###### [Lookup Asset (Insight) Objects from AQL (IQL)](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/lookup-asset-insight-objects-from-aql-iql)

Use this action to look up an Asset (Insight) object from AQL/IQL and include the result in other actions. 

###### [Update Asset](https://docs.adaptavist.com/sr4js/latest/integrations/automation-for-jira/update-asset)

Use this action to update an Assets (Insight) object.
