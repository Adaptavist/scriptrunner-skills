- Space: SMS
- Hierarchy: scriptrunner-migration-suite-web-app
- Doc ID: doc-sms-574522372

The Web App has three main points of navigation: 

-   [Navigate to features](#id-.ScriptRunnerMigrationSuiteWebAppNavigationv2.0-features)
-   [Navigate to support tools and resources](#id-.ScriptRunnerMigrationSuiteWebAppNavigationv2.0-resources)
-   [Navigate to settings](#id-.ScriptRunnerMigrationSuiteWebAppNavigationv2.0-settings)

## Navigate to features 

You can find the main feature navigation on the left-hand side of the Web App:

![](/sms/files/latest/574522372/574522368/1/1785259869000/main-navigation.png)

Using these, you can navigate to:

-   The Home screen
-   The new [Projects](#id-.ScriptRunnerMigrationSuiteVersion2ReleaseNotesvDraft-project) feature
-   The [Analyse and Assess Tool](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-analyse-and-assess-tool)
-   The [Migration Agent](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-agent)
-   The [Dev and Deployment Tool documentation](https://docs.adaptavist.com/sms/latest/scriptrunner-dev-and-deployment-tool)

## Navigate to support tools and resources 

Use the bottom left-hand navigation to find support tools and resources:

![](/sms/files/latest/574522372/585009408/1/1787596805000/nav-2.png)

-   Select **Help and Resources**, to select the following resources: 
    -   **Raise support ticket**: Sends you to [the support portal](https://the-adaptavist-group-support.atlassian.net/servicedesk/customer/portal/1069/user/login?destination=portal%2F1069).
    -   **Training**: Sends you to the [Training](https://docs.adaptavist.com/sms/latest/training) module of the documentation.
    -   **Documentation**: Sends you to the product [documentation](https://docs.adaptavist.com/sms/latest). 
    -   **Feedback** to navigate to a [feedback](https://docs.google.com/forms/d/e/1FAIpQLSeo-YAZ2tma3LxsuDFsTgSFjj_WpnqcUiWqsHFPCIVFUgHs4Q/viewform) form.
-   Select **Terms of Service** to load the _ScriptRunner Migration Suite Terms of Service_.

## Navigate to settings 

To navigate to settings, select ![](/sms/files/latest/574522372/574522370/1/1785259869000/settings-button.png) next to your username: 

![](/sms/files/latest/574522372/585009410/2/1788958815187/nav-3.png)

From there, you can: 

-   View and create **[API Keys](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/api-keys)**
-   **[Import Chats](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/migrate-from-version-1-to-version-2)** from version 1 of the ScriptRunner Migration Suite
-   Change the **Theme** to _Light_, _Dark_, and _System_
-   Review **Cookie Preferences**
-   **Switch Region** (learn more about this in [Data Residency and Privacy](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/data-residency-and-privacy))
-   **Log Out**
