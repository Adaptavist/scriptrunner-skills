# Bulk Purge Trash

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Features > Built-In Scripts > Space Administration Built-In Scripts
- Doc ID: doc-sr4c-139659d9-e676-4360-a9ca-d75859ed759f-7a2b68de059e4ccb
- Source: https://docs.adaptavist.com/sr4c/latest/features#built-in-scripts--en#space-administration-built-in-scripts--en#bulk-purge-trash--en

Use this script to purge all trash for specific spaces or all spaces in your Confluence instance that you have admin permissions to

## Run this script

Follow these steps to run the built-in script:

1.  Select Space Tools from the bottom left-hand corner of the screen.
2.  Select Advanced Space Functionality.
3.  Select Bulk Purge Trash
4.  Select an option for Trash to Delete.
    
    -   _All Spaces_
        
        Note: This option only purges the trash in the spaces you have permission to do so.
        
        If you have Confluence System Administrator access, it purges the trash of all spaces in the instance of Confluence.
        
    -   _Select Spaces_, and then enter your desired spaces in the Space(s) field.
        
        Note: You can only select spaces where you have administrator permissions.
        
    
5.  Select Run.
    
    You can select Preview instead of Run to view changes before implementing them.
    

Once you select Run, the Result of the script appears.

## Example

Purge all trash

Follow these steps to delete all the trash were you have admin permissions in your Confluence instance:

1.  Select Space Tools from the bottom left-hand corner of the screen.
2.  Select Advanced Space Functionality.
3.  Select Bulk Purge Trash.
4.  Select All Spaces for Trash to Delete.
5.  Select Run.
