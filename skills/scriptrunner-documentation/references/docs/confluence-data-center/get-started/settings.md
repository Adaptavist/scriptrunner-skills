Information on the Settings page, where System Administrators can make changes to the app.

The Settings page is only accessible for Confluence users with System Administrators permission.

There are two ways to navigate to the Settings page:

-   Once you navigate to Confluence Administration (selecting the Cog button and then selecting General Configuration), you can select Settings from the left-hand navigation menu under the ScriptRunner heading:
-   You can select the Settings button from the upper right-hand corner of the screen once you navigate into ScriptRunner:
