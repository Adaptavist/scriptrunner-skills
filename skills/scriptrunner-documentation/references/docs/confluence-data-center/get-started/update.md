## Update ScriptRunner for Confluence

Learn how to update your app for the lastest versions.

There are two ways to update ScriptRunner for Confluence:

### Version History on the Atlassian Marketplace

1.  To update ScriptRunner for Confluence, navigate to [Version History](https://marketplace.atlassian.com/apps/1215215/scriptrunner-for-confluence/version-history).
    
    From there, you can select a version to Download.
    
2.  You can also click Watch in the upper right-hand corner to be notified when new versions are released.

### Manage Apps in Confluence Instance

If you navigate to General Configuration > Manage Apps, you can update by selecting Update.

Navigate to General Configuration > Manage Apps and select Update.
