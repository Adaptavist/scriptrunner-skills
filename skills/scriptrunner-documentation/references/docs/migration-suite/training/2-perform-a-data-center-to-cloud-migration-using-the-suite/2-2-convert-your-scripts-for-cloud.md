# 2.2 Convert your scripts for Cloud

- Platform: migration-suite

In the previous module, while scoping our migration, we identified migration blockers and warnings that need to be addressed. So, what’s the next step?  
The **Migration Agent** is a tool designed to understand the root cause of these blockers and determine the best way to resolve them.  
  
In this video, we'll use the **Migration Agent** to help us:

1.  Deepen our understanding of the findings from our migration analysis.
    
2.  Identify custom solutions for our specific migration scenarios, such as achieving feature parity.
    
3.  Convert Data Center scripts to resolve our migration blockers.
    

Note:

The Migration Agent tool uses AI and, like all AI tools, is capable of making mistakes and may not always provide perfect information. We recommend verifying any information or results obtained from the Migration Agent tool before use, to ensure accuracy and relevance to your specific needs.
