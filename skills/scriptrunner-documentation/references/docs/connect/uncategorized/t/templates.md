# Templates

- Platform: connect
- Space: SRC
- Hierarchy: n/a
- Doc ID: doc-src-194675462
- Source: https://docs.adaptavist.com/src/latest/templates

Using templates for common automation use cases can save you lots of time compared to scripting from scratch. 

A template is a selection of specific connections, triggers, and pre-written code packaged to solve a specific use case. For example, whenever a Jira work item is created in a space, you can use ScriptRunner Connect to auto-create a Confluence page that links to the Jira work item and populates the page with specified fields from the Jira work item.

Click **Templates** in the navigation panel to access the module and view the available templates.
