# Macros

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: features
- Doc ID: doc-sr4cc-114204643
- Source: https://docs.adaptavist.com/sr4cc/latest/features/macros

Macros can be configured to enhance the content on your Confluence pages. Macros make your organization’s pages easier to use for both editors and viewers by giving them the information they need or smarter ways to build content.

There are two types of macros available: 

-   [Built-In Macros](https://docs.adaptavist.com/sr4cc/latest/features/macros/built-in-macros)
-   [Custom Macros](https://docs.adaptavist.com/sr4cc/latest/features/macros/custom-macros)

## View macros in your instance

To navigate to the macros, follow these steps: 

1.  Select the **Settings** cog in the upper right-hand corner of the screen.   
    ![](/sr4cc/files/latest/114204643/115718166/1/1627670185000/settings.png)
2.  Under _Settings_, expand the _ScriptRunner_ section and select **Macros**._![](/sr4cc/files/latest/114204643/246187281/1/1711386866000/macro-nav.png)  
    _
    
    From here, you can view the macros.  
    ![](/sr4cc/files/latest/114204643/246187284/1/1710872173000/macro_homescreen.png) 
    
    Action menu
    
    You can use the _Actions_ menu to edit, enable, and delete your custom macros. This menu does not work for built-in macros.
    
    ![](/sr4cc/files/latest/114204643/246187283/1/1710872346000/macro_action.png)
    

## Use macros

You can choose your custom macro when you edit a Confluence Cloud page. 

1.  Select the macro browser, and start typing the name of your macro in the field.   
    ![](/sr4cc/files/latest/114204643/125502773/1/1629754027000/usecustommacro.png)  
      
    
    View all macros
    
    If you don't know the name of the macro you want to use, select **View More** to view a list of all macros.
    
2.  Once your macro appears, select it. 
3.  Enter any required information when the macro and the right sidebar appears.
    
    Macro tips
    
    -   A macro editor screen appears here if you are using a macro that has a _Plain Text_ body type.
    -   In this particular example, clicking **Edit to setup** on the macro that appeared made the right sidebar appear. Macros will vary.
    
      
    ![](/sr4cc/files/latest/114204643/125502772/3/1710872173000/usemacro2.png).
