# Confluence Administration Built-In Script

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: features > built-in-scripts
- Doc ID: doc-sr4cc-114204311
- Source: https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script

Confluence administrators can make changes globally with any of the built-in scripts.

## Navigation

1.  Navigate to _ScriptRunner_ and select **Built-In Scripts**.   
    ![](/sr4cc/files/latest/114204311/588874150/1/1769186537000/built-in-scripts.png)
    
2.  Choose the script you would like to use.  
    
    -   [Bulk Add or Remove Labels on One or More Pages](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/bulk-add-or-remove-labels-on-one-or-more-pages)
    -   [Bulk Delete Attachments](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/bulk-delete-attachments)
    -   [Bulk Delete Comments from One or More Pages](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/bulk-delete-comments-from-one-or-more-pages)
    -   [Bulk Purge Trash](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/bulk-purge-trash)
    -   [Copy Page Tree](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/copy-page-tree)
    -   [Copy Space](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/copy-space)
    -   [Delete Page Tree](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/delete-page-tree)
    -   [Rename Labels](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-script/rename-labels)
    
3.  Complete the required fields.
    
    Each script is different and has different fields to fill out.
    
4.  Select **Run.**
    

After you select **Run**, your results will appear.
