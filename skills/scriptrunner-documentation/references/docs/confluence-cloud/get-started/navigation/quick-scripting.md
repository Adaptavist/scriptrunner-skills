Information about the features and how to navigate the Quick Scripting page.

Use the _Quick Scripting_ page to search and discover ScriptRunner features, including scripts and macros.

1.  Type a keyword into the Search bar.
    
    This is a free-text field, so you can search any keyword. In this example, _Create_ was entered.
    
2.  Select one of the four categories to refine your search results:
    
    -   Administer
    -   Automate
    -   Customise
    -   Extend
    
    The Administer category is chosen in this example, and it is highlighted in blue with filtered results. Categories that do not contain results are grayed out.
    
    Note: Notice that the categories and script type are indicated on the right side of the search results.
    
3.  Select a search result to open the feature or script.
    
    In this example, selecting Create a Page Hierarchy with Templates opens _Script Listener_ for that script.
