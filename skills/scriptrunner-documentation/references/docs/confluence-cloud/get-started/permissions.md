# Permissions

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: get-started
- Doc ID: doc-sr4cc-171278734

You must have administrator rights to use ScriptRunner for Confluence Cloud. For more information on each type of permission, please visit [Atlassian's Confluence Cloud Administration docs](https://support.atlassian.com/confluence-cloud/docs/get-started-as-confluence-cloud-administrator/).
