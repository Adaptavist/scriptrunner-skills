How to disable and re-enable features in the app for troubleshooting.

If you are having issues with a specific feature of ScriptRunner, we suggest disabling all ScriptRunner scripts for that feature and re-enabling one-by-one to identify the source of the problem. For example, to troubleshoot macros:

1.  Navigate to Macros.
2.  Click the Cog drop-down under _Actions_.
3.  Select Disable from the list.
4.  Repeat this for all configured macros.
5.  Re-enable macros one by one and test.
