# Confluence Administration Built-In Scripts

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: Features > Built-In Scripts
- Doc ID: doc-sr4cc-15f9e484-c28c-4199-8669-ca49d2b4df0a-b38247bd7baf209f
- Source: https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts

Learn about our built-in scripts that complete functions related to Confluence administration.

Confluence administrators can make changes globally with any of the built-in scripts.

## Navigation

1.  Navigate to ScriptRunner and select Built-in Scripts.
    
2.  Choose the script you would like to use.
    
    -   [Bulk Add or Remove Labels on One or More Pages](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/bulk-add-or-remove-labels-on-one-or-more-pages)
    -   [Bulk Delete Attachments](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/bulk-delete-attachments)
    -   [Bulk Delete Comments from One or More Pages](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/bulk-delete-comments-from-one-or-more-pages)
    -   [Bulk Purge Trash](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/bulk-purge-trash)
    -   [Copy Page Tree](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/copy-page-tree)
    -   [Copy Space](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/copy-space)
    -   [Delete Page Tree](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/delete-page-tree)
    -   [Rename Labels](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/confluence-administration-built-in-scripts/rename-labels)
3.  Complete the required fields.
    
    Tip: Each script is different and has different fields to fill out.
    
4.  Select Run.
    

After you select Run, your results appear.
