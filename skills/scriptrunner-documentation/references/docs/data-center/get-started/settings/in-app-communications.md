# In-App Communications

- Platform: data-center
- Space: SR4JS
- Hierarchy: Get Started > Settings
- Doc ID: doc-sr4js-faebca03-704b-499c-85a3-4084afdcf3ee-37dc379835381e7a
- Source: https://docs.adaptavist.com/sr4js/latest/get-started/settings/in-app-communications

The In-App Inbox is a feature in ScriptRunner that, when enabled, allows ScriptRunner to show notifications in the Inbox when viewing a ScriptRunner admin screen.

We may use the inbox to show information about breaking changes, recommended upgrades, new releases and other important updates. When disabled, no information will display in the inbox.

Note: If you're unable to see inbox messages, it could be due to firewall restrictions.

## How to enable/disable

The In-App Inbox is enabled by default. To enable or disable In-App Inbox follow the steps below:

1.  From ScriptRunner, select Settings.
    
2.  Select the Instance Settings tab.
3.  Toggle the _In-App Inbox_ on/off.
