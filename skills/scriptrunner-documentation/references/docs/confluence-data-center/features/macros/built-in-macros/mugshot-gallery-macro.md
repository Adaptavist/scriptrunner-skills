# Mugshot Gallery Macro

The _Mugshot Gallery_ macro shows profile pictures of group members in tabular format for a group.

For example, you can show the images of group members on a page.

This macro cannot be edited, but you can disable it.

If you disable it in the instance, users will not be able to use it when working with Confluence pages in the instance.

## Use the Mugshot Gallery macro on a Confluence page

Follow these steps to use the _Mugshot Gallery_ macro:

1.  Select Insert, and then select Other Macros.
    
2.  Select the Mugshot Gallery macro from the provided list.
    
3.  Enter the name of a Confluence group in the Group field.
    
    Tip: For more information on users and groups, visit the Atlassian documentation: [Add users and set permissions](https://confluence.atlassian.com/conf59/add-users-and-set-permissions-792498553.html).
    
4.  Specify the number of profile pictures you want to see in a row for Profile Per Row.
5.  Select Preview to see the gallery in the macro editor.
    
    Note: This macro shows the first 200 members of a group returned by Confluence API.
    
    The macro will not show users that have disabled accounts.
    
6.  Select Insert, and the macro placeholder appears.
    
7.  Save the page.

The mugshot gallery appears on the page. When the page is saved or refreshed, the gallery is updated.
