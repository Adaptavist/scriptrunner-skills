# User Editor Settings

- Platform: data-center
- Space: SR4JS
- Hierarchy: Get Started > Settings
- Doc ID: doc-sr4js-7c609b84-881a-437a-85c4-4a582386d7cb-b9744e07190ffdb3
- Source: https://docs.adaptavist.com/sr4js/latest/get-started/settings/user-editor-settings

The _User Editor_ setting allows you to enable or disable the editor minimap. The [minimap](https://code.visualstudio.com/docs/getstarted/userinterface#_minimap) is visible on the right-hand side of your script. When you write a script, the minimap can be useful for navigating, and understanding, large areas of code. The minimap is enabled by default, however you may wish to disable this feature if you don't find it useful.

## How to enable/disable user editor settings

Note: Making a change to _User Editor Settings_ only impacts the current user. Each user can have their own preference.

1.  From ScriptRunner, select Settings.
    
2.  Under User Settings, toggle the _Show Editor Minimap_ option on or off.
