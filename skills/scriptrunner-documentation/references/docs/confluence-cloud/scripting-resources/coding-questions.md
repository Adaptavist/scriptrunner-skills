Find information about common coding questions related to ScriptRunner for Confluence Cloud.

You might encounter difficulties due to a bug, or you might have a configuration or coding question. Follow these steps to request help:

Tip: Be sure to mention that you are using the Cloud version of ScriptRunner.

-   If it is a bug in the plugin, create an issue in the [Adaptavist Product Support Portal](https://productsupport.adaptavist.com/servicedesk/customer/portal/40/create/269).
-   If it's a general configuration issue with the plugin, open a support request in the [Adaptavist Product Support Portal](https://the-adaptavist-group-support.atlassian.net/servicedesk/customer/portal/18)
-   If it's a coding question (like how to accomplish something with the API), ask a question on the [Atlassian Community](https://community.atlassian.com/t5/tag/addon-com.onresolve.confluence.groovy.groovyrunner/tg-p).
    
    Tip: Community is the widest audience, so this is the best place to get an answer to your specific coding question. Mention that you're using the ScriptRunner add-on.
