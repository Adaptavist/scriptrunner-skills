# In-App Communications

- Platform: confluence-data-center

The In-App Inbox is a feature in ScriptRunner that, when enabled, allows ScriptRunner to show notifications in the Inbox when viewing a ScriptRunner admin screen.

We may use in-app notifications to show information about security issues, recommended upgrades, survey requests, or licensing offers. When disabled, these notifications won't be displayed.

Tip: If you're unable to see inbox messages, it could be due to firewall restrictions.

To enable or disable _In-App Communications_ follow the steps below:

1.  From ScriptRunner, select Settings.
2.  Toggle In-App Communications on/off.
