There are two main ways to navigate to ScriptRunner in Jira:

-   [Through the _Jira Administration_ menu](#id-.Navigationv9.x-admin-nav)
    
-   [Using the _Administration_ quick search](#id-.Navigationv9.x-quick-search)
    

Read more about each in the sections below.

## Navigating from the Administration menu

ScriptRunner is a tab in the _Administration_ console.

![Image of ScriptRunner tab location](/sr4js/files/latest/442888652/442888665/1/1758746959000/ScriptRunner_tab.png)

To access ScriptRunner, select the **Cog** icon to open the _Administration_ menu and select **ScriptRunner**.

![Image of ScriptRunner option in the Administration menu](/sr4js/files/latest/442888652/442888672/1/1758746959000/SR-from-admin-cog.jpg)

## Navigating using the quick search

1.  Press the keyboard shortcut `gg`. A search dialog appears.
    
2.  Type **ScriptRunner** into the search and press `Enter` to be taken to the ScriptRunner [_Browse_ page](#id-.Navigationv9.x-browse).
    
    ![Image of scriptrunner being entered into search](/sr4js/files/latest/442888652/442888670/1/1758746959000/GG-search.jpg)

Alternatively, you can select one of the related options, such as **Built-in Scripts.**

## Browse feature navigation

Use the _Browse_ page to search and discover all the functionality ScriptRunner has to offer. Save time by typing keywords into the search bar to filter scripts by name or goal, or select categories and filters to discover scripts. To navigate to the Browse page, click **ScriptRunner** from the Jira _Administration_ menu.

![Image of the Browse page](/sr4js/files/latest/442888652/442888660/1/1758746958000/Browse_feature.png)

### Browse feature components

Four components make up the _Browse_ page:

1.  The **Search** field - Use this free text field to search for keywords.
    
2.  Categories - Select a category to constrain by functionality.
    
3.  Filters - Narrow down a category or search results using filters.
    
4.  Script descriptions - Click the results to navigate to relevant script configuration pages.
    

![Image of Browse feature sections](/sr4js/files/latest/442888652/442888654/1/1758746958000/Browse_feature_sections.png)
