# View Server Log Files

- Platform: data-center
- Space: SR4JS
- Hierarchy: Features > Built-in scripts
- Doc ID: doc-sr4js-688c5951-6b01-4ec0-bdfe-414d1b59ec54-f5280f3e2fb0ff38
- Source: https://docs.adaptavist.com/sr4js/latest/features#built-in-scripts--en#view-server-log-files--en

Use _View Server Log Files_ to show the last N lines of application log files. Follow these steps to run the built-in script:

1.  Navigate to Built-in Scripts > View Server Log Files.
2.  Select the log file to view in Log File.
3.  Enter the number of lines to display in Number of Lines.
    
    The script returns the last N number of lines from the log file.
    
4.  Click Run to view the results.
    
    You can select Preview instead of Run to view changes before implementing them.
    

Once you select Run, the _Results_ of the script appear.

Tip: Increase the logging level to help debug scripts. See [logging levels](https://docs.adaptavist.com/sr4js/latest/best-practices/logging/advanced-logging#log-levels--en) for more information

.

Note: For information on more advanced logging in ScriptRunner see [Advanced Logging](https://docs.adaptavist.com/sr4js/latest/best-practices/logging/advanced-logging).
