# Built-In Macros

- Platform: confluence-data-center
- Space: SR4C

Macros are small code generators that perform a task. The following documentation explains built-in macros, which are included in ScriptRunner for Confluence.

Customization is not required for bundled macros. This documentation is sorted by macro in alphabetical order.

The library of bundled macros is expanding. New macros are added based on need. If there is a macro that would be useful to you, let us know [here](https://the-adaptavist-group-support.atlassian.net/servicedesk/customer/portal/13).

Eventually, you'll be building these macros yourself. For more information on building macros yourself, visit [Custom Macros](https://docs.adaptavist.com/sr4c/latest/features/macros/create-custom-macro).
