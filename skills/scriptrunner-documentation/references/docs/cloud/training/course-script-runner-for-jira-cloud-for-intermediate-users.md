# Course: ScriptRunner for Jira Cloud for Intermediate Users

- Platform: cloud
- Space: SR4JC
- Hierarchy: training
- Doc ID: doc-sr4jc-121903404
- Source: https://docs.adaptavist.com/sr4jc/latest/training/course-scriptrunner-for-jira-cloud-for-intermediate-users

This course introduces the most powerful user-driven features of ScriptRunner and aims to give users the core information and skills they need to start taking advantage of ScriptRunner's customization and automation potential. It introduces the two languages you will use to control and customise Jira - Jira Expressions and Groovy. It covers the essentials of the Jira REST API and how to use it. And it walks users through modifying existing scripts, combining scripts, and techniques and best practices that ensure you can start using ScriptRunner and Jira Cloud to their full potential.
