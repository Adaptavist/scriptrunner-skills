[Jobs](https://docs.adaptavist.com/sr4c/latest/features/jobs) are a way to run code at specific times of the day/week/month or on an interval in order to perform an automated task.

Use _List Scheduled Jobs_ to view details of all jobs on the current instance.

## Run this script

1.  Navigate toGeneral Configuration > ScriptRunner > Built-in Scripts.
2.  Select List Scheduled Jobs.
3.  There are no fields for this built-in script, so you only have to select Run or Preview.

The Result shows the _Job ID_, _Interval/Cron_, _Next Run_, and _Run Mode_ of each job, listed below the feature they run.
