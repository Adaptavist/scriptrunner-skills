# Built-In Listeners

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Features > Event Listeners
- Doc ID: doc-sr4c-8e234d83-cde5-4e14-b840-76d099d2618b-fe9d6173706a2a89
- Source: https://docs.adaptavist.com/sr4c/latest/features#event-listeners--en#built-in-listeners--en

Built-in listeners are available for you to use when you install ScriptRunner for Confluence.

To use one of these listeners, follow these steps:

1.  Navigate to Confluence Administration by selecting the Cog button and then selecting General Configuration.
2.  In the left menu bar, under _ScriptRunner_, navigate to Listeners.
3.  Select Create Listener.
    
    Note: If you're unsure about how to get started, consider clicking the Add Examples button and select from a list of pre-configured examples. If you choose to add example(s), they will be disabled by default until you enable them.
    
4.  Select one of the following built-in listeners:
    
    -   [Add/Remove Watchers Listener](https://docs.adaptavist.com/sr4c/latest/features/event-listeners/built-in-listeners/add-or-remove-watchers-listener)
    -   [Inherit Parent Permissions For New Pages Listener](https://docs.adaptavist.com/sr4c/latest/features/event-listeners/built-in-listeners/inherit-parent-permissions-for-new-pages-listener)
    -   [Manage Labels Listener](https://docs.adaptavist.com/sr4c/latest/features/event-listeners/built-in-listeners/manage-labels-listener)
    -   [Send Custom Email](https://docs.adaptavist.com/sr4c/latest/features/event-listeners/built-in-listeners/send-custom-email)
    -   [Update Page Restrictions Listener](https://docs.adaptavist.com/sr4c/latest/features/event-listeners/built-in-listeners/update-page-restrictions-listener)
    
5.  Fill out the form that appears.
    
    Tip: For help with the form, follow the link that corresponds with the listener from the above step.
    
6.  Save the listener.
