## Welcome to ScriptRunner Migration Suite Version 2!

We have a newly designed, more robust and scalable version of the ScriptRunner Migration Suite Web App! You can now store your chats and analysis in a project, share your projects amongst your organization, run bulk conversions, and create and manage API keys from within the app. Additionally, the Web App has been redesigned and navigation has been enhanced. Keep reading for more information on the updates.

To access new features and improvements across the toolset, you need to log in from a new URL, but your existing login details remain the same. You can migrate any active projects to the new version using the instructions below.

## Migrate from version 1 to version 2

Version 1 of the ScriptRunner Migration Suite will become read-only and eventually retired. We recommend moving to the new version as soon as you're able. For tips about migrating your ScriptRunner Migration Suite content from Version 1 to Version 2, check out [Migrate from version 1 to version 2](../../script-runner-migration-suite-web-app/migrate-from-version-1-to-version-2.md).

We have added a feature to export your Migration Agent chats from version 1 and import them into version 2 to make sure you can keep historical data.

## New navigation

The navigation of the ScriptRunner Migration Suite Web App has changed. All navigation is done from the left-hand navigation bar. From here, you will navigate to all features, support tools, resources, API keys, and settings.

For more information, visit the [Web App Navigation](../../script-runner-migration-suite-web-app/web-app-navigation.md) documentation.

## New Projects feature

We have changed the way data is grouped in the ScriptRunner Migration Suite. Now, all chats and analysis are contained in a [Project](../../script-runner-migration-suite-web-app/projects.md). ## Share your chats and analysis within your organization

Previously, chats and instance analysis were only available to the user who created them. Now, they can be shared within your organization by changing the Visibility of a Project.

Learn more in the [Create Project documentation](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/projects#create-a-project--en).

## Convert your scripts in bulk

You can now bulk convert scripts in an analysis to Cloud scripts, and then export them to the [ScriptRunner Dev and Deployment Tool](script-runner-dev-and-deployment-tool.md).

Learn more in the [Bulk Convert Your Scripts](../../script-runner-migration-suite-web-app/script-runner-migration-analyse-and-assess-tool/bulk-convert-your-scripts.md) documentation.

## New API key creation and management

You can now create and manage personal credentials for scripts and integrations that use the ScriptRunner Migration Suite API.

Learn more in the [API Keys](../../script-runner-migration-suite-web-app/api-keys.md) documentation.

## Migration Agent updates

In addition to the redesign and ability to contain chats in a Project, the Migration Agent has been enhanced to:

-   Answer questions about ScriptRunner for Confluence.
-   Be a more intelligent and efficient agent.
-   Convert scripts in a better way.
-   Contain a stronger version of ScriptRunner Intelligence.

Remember, the Migration Agent is built for ScriptRunner, Jira Cloud, and Confluence APIs. It is the most efficient AI tool to use for ScriptRunner for Jira Cloud. Learn more about how the agent outperforms generic AI in migration to Cloud [here](https://www.scriptrunnerhq.com/inspiration/blog/how-scriptrunner-migration-suite-outperforms-generic-ai-in-cloud-migrations).

Learn more in the [Migration Agent documentation](../../script-runner-migration-suite-web-app/script-runner-migration-agent.md).
