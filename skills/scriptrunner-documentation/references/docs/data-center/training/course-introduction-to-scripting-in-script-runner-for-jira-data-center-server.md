# Course: Introduction to Scripting in ScriptRunner for Jira Data Center/Server

- Platform: data-center
- Space: SR4JS
- Hierarchy: training
- Doc ID: doc-sr4js-443372234
- Source: https://docs.adaptavist.com/sr4js/latest/training/course-introduction-to-scripting-in-scriptrunner-for-jira-data-center-server

This course aims to give users the core information and skills they need to start taking advantage of ScriptRunner's customization and automation potential. It introduces the Groovy scripting language and Atlassian's Java API, and walks through modifying existing scripts so users less familiar with coding can take advantage of ScriptRunner's most powerful features.

You may also want to check out the [user documentation](https://docs.adaptavist.com/sr4js/latest/hapi) for HAPI.

HAPI is an API (application programming interface) we've developed for users to create automations and customizations faster than ever.
