# View Server Log Files

- Space: SR4C
- Hierarchy: Features > Built-In Scripts > Confluence Administration Built-In Scripts
- Doc ID: doc-sr4c-b9650f58-312b-4d30-90a1-0e676a1e833d-01a5bb55b9250ab9
- Source: https://docs.adaptavist.com/sr4c/latest/features#built-in-scripts--en#confluence-administration-built-in-scripts--en#view-server-log-files--en

Use _View Server Log Files_ to show the last lines of your instance's application log files.

## Run the script

To run the script, follow these steps:

1.  Navigate to General Configuration > ScriptRunner > Built-in Scripts.
2.  Select View Server Log Files.
3.  Select the log file to view in Log File.
    
    For ScriptRunner for Confluence, this is automatically set with _atlassian-confluence.log_.
    
4.  Enter the number of lines to display in Number of Lines.
5.  Select Run.
    
    You can also select Preview to view changes before running the script.
