# Ceasing Development on Confluence 6

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Release Notes
- Doc ID: doc-sr4c-dc82f9c3-75f5-45d7-83d3-0eb957c39a43-02a8720a6b0e14f5
- Source: https://docs.adaptavist.com/sr4c/latest/release-notes/ceasing-development-on-confluence-6

Following Atlassian's decision to drop IE11 Support in Atlaskit (Atlassian's UI library), Adaptavist is no longer developing new features for ScriptRunner versions running on Confluence 6.

Limiting development on ScriptRunner versions on Confluence 6 allows us to prioritise development on Confluence 7+ versions, benefiting the majority of our users. These changes mean that we are no longer fixing bugs or developing new ScriptRunner features that are compatible with these versions of ScriptRunner.

Note: Adaptavist will continue to fix critical security vulnerabilities in all versions of ScriptRunner running on Atlassian-supported platform versions.

Note: We will continue to support customers using ScriptRunner on Atlassian software versions until their end of life (Confluence 6.15: 14th March 2021).
