# Feature Release Summary

- Platform: data-center
- Space: SR4JS
- Hierarchy: release-notes
- Doc ID: doc-sr4js-443371830
- Source: https://docs.adaptavist.com/sr4js/latest/release-notes/feature-release-summary

Welcome to the summary hub, where you can explore all the feature releases we've introduced to ScriptRunner for Jira, starting from version 7.0.0 onwards. This hub is designed to assist you in finding the ideal version to upgrade to, all while catching up on any enhancements you might have missed since your last update.

This page focuses on feature updates only and does not contain documentation updates or bug fixes.
