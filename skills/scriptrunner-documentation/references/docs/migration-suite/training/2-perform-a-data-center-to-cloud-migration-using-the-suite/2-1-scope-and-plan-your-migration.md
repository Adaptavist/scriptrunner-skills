# 2.1 Scope and plan your migration

- Platform: migration-suite
- Space: SMS
- Hierarchy: training > 2-perform-a-data-center-to-cloud-migration-using-the-suite
- Doc ID: doc-sms-477864785
- Source: https://docs.adaptavist.com/sms/latest/training/2-perform-a-data-center-to-cloud-migration-using-the-suite/2-1-scope-and-plan-your-migration

Until now, manually scoping a migration has been a time-consuming process. However, it's a critical step in the migration process that enables our teams to determine the complexity of a migration and avoid surprises.  
  
The **Analyse and Assess** tool streamlines this process by analysing uploaded scripts and configurations, assessing their Cloud readiness, then providing a high-level report of the migration work required. Additionally, we can delve further into this analysis to obtain deeper insights and determine necessary actions.

  

Wondering how to get Data Center scripts into the ScriptRunner Migration Suite for analysis?

We recommend using the ScriptRunner for Jira **DC Export Button**. In the demo below, Bobby explains how it's used and where you'll find it in your Jira instance. For further details, see the [Script Registry](https://docs.adaptavist.com/x/kAGiH "https://docs.adaptavist.com/x/kAGiH") documentation.
