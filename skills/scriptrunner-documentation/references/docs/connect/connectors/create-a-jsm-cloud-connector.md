# Create a JSM Cloud Connector

- Platform: connect
- Space: SRC
- Hierarchy: connectors
- Doc ID: doc-src-237864751
- Source: https://docs.adaptavist.com/src/latest/connectors/create-a-jsm-cloud-connector

Making new connectors for Atlassian apps is a breeze. In this example, we'll create a connector for Jira Service Management (JSM) Cloud. Follow along!

1.  Click **Connectors** on the left side of the page.  
    The _Connectors_ module opens in the app.  
      
    
2.  Click **Create Connector** (or **Create New** if you've created connectors in the past).  
    ![The Create Connector option highlighted in the Connectors module.](/src/files/latest/237864751/339512688/2/1756151195000/create-new-connector.png)  
    The _Create connector_ screen appears.  
      
    
3.  Select the **Jira Service Management Cloud** connector.  
    The _Create connector_ dialog appears.  
      
    
4.  Enter a **name** for the connector, then click **Continue**.  
    ![The ](/src/files/latest/237864751/426968098/1/1756151320000/continue-with-connector.png)  
    The _Configure Connector_ dialog appears.  
      
    
5.  Enter your service account email address, or click **Next** to use your primary Atlassian account.![The configure connector dialog, in the add email step.](/src/files/latest/237864751/326369788/1/1738614556000/JSM-cloud-service-email.png)  
      
    
6.  Select your preferred instance type, the ScriptRunner Connect managed app or the self-managed Atlassian Cloud app option, then click **Next**.  
    ![The select instance type screen in the create connector dialog screen.](/src/files/latest/237864751/326369787/1/1738614826000/JSM-Cloud-instance-selection.png)  
      
    
7.  Click **Authorize**.  
    ![The ](/src/files/latest/237864751/326369786/1/1738615348000/JSM-Cloud-authorize.png)  
     App authorization permissions open.  
      
    
8.  Select your desired option for the **Authorize for site** dropdown, review the permissions, then click **Accept**.  
    ![The access request screen with the ](/src/files/latest/237864751/326369785/1/1738616412000/JSM-Cloud-permissions.png)  
      
    
9.  Reselect the site in the **Site** dropdown, then click **Confirm**.  
    ![The configure connector dialog with the ](/src/files/latest/237864751/237864756/1/1709755024000/select-site-wizard.png)
    
10.  Click **Done** to exit the _Manage connector_ screen.  
     ![The new connector is shown as connected, the ](/src/files/latest/237864751/426968097/1/1756151543000/done.png)  
     A success message appears in the app, and your new JSM Cloud connector is created.  
     
     Successfully set up connectors are given an Authorized icon in the _Connectors_ screen.  
     ![The ](/src/files/latest/237864751/426968096/1/1756151619000/2025-08-25_14-41-21.png)
