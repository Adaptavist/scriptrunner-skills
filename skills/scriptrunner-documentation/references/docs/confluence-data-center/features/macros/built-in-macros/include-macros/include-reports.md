# Include Reports

- Platform: confluence-data-center
- Space: SR4C

- Source: https://docs.adaptavist.com/sr4c/latest/features#macros--en#built-in-macros--en#include-macros--en#include-reports--en

Use the _Includes Report_ macro with the _Include Version_ macro to keep track of versioning and links to the different places the pages are used, also called diffs.

This macro includes which pages have later versions with links to the different places they are used.

This macro provides a button to Update All, which updates all included pages to the latest version number. Make sure to check the diffs first to confirm this is the needed version number. When this macro is used, it creates and saves a new version of the current page. You can roll the page back to a previous version if it wasn't the result you wanted.
