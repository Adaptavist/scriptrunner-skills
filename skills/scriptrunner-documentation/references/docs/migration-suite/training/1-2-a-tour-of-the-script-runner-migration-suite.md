The ScriptRunner Migration Suite consists of three tools, each designed to support a specific phase of your Cloud migration journey:

-   Analyse
-   Migration Agent
-   Dev and Deployment

It's important to note that while these tools are part of the ScriptRunner Migration Suite, they are accessed in different ways. The Analyse tool and Migration Agent are available in the web app, while the Dev and Deployment tool is provided through a repository. Let's explore how to access each tool and their core functionalities, starting with the web app.
