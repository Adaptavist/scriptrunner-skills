# HAPI Code Helper

We've added a HAPI code helper, also known as a linter, that detects where your scripts can be simplified with HAPI code and suggests an alternative.

![GIF demonstrating the HAPI code helper in use](/sr4js/files/latest/442888886/441363960/1/1727946783000/HAPI+helper+GIF.gif)

This helper is enabled by default, however, we understand that not everyone wants scripting suggestions and you may wish to disable the helper. 

## How to enable/disable the HAPI code helper

Changing the _HAPI Code Helper_ default setting only impacts the current user. Users can set their own individual preferences.

1.  Navigate to ScriptRunner and select **Settings**.  
    ![Image of Settings options](/sr4js/files/latest/442888886/442888887/1/1758746978000/Settings_options.png)
2.  Toggle the _HAPI Code Helper_ option on or off within the **User Settings** tab.  
    ![Image of HAPI code helper toggle](/sr4js/files/latest/442888886/442888890/5/1737459148000/HAPI_code_helper.png)
