## What happens when my ScriptRunner license expires?

Server

If your Server license expires, the app should continue to work. However, you will no longer be entitled to the following:

-   Upgrades to new versions
-   Bug fixes/new features
-   Support from us per our [SLA](https://www.adaptavist.com/atlassian-apps/product-sla/).

We strongly advise you to keep your license up to date so that if you run into issues, you are entitled to receive support from us.

Data Center

If your Data Center license expires, your ScriptRunner instance will stop working, and scripts will no longer run. However, your configuration will not be lost, and everything ScriptRunner will resume as soon as your license is renewed.
