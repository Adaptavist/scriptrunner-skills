By simplifying complex tasks and making migrations more predictable, the ScriptRunner Migration Suite can support your teams at every stage of the migration process.   
  
In this short course, we've highlighted just a few of the challenges that these tools can help you overcome. However, we're confident that you'll discover many more ways the suite can accelerate your team's journey beyond the use cases presented here! 

  

Now it’s your turn: explore the tools for yourself

This exercise gives you a chance to try out the **ScriptRunner Migration Suite** using a set of provided example scripts, so you can explore the tools without needing to use your own script export.

To get started:

1.  **Download** the **[example project scripts zip](https://docs.adaptavist.com/sms/files/latest/477864956/477864957/1/1765535310000/sms-training-examples.zip)**.
2.  **Upload** the zip file to the **[Analyse and Assess](https://migrationsuite.scriptrunnerhq.com/)** tool to generate a migration report and review the findings.
3.  **Click** through the configurations to access the **[Migration Agent](https://migrationsuite.scriptrunnerhq.com/)**, gain contextual understanding, and practise converting scripts. 
4.  Optionally, **use** the **[Dev and Deployment](https://bitbucket.org/adaptavistlabs/migration-example-project/)** tool to deploy converted scripts to a test environment. 

  

 You’ve now finished this course— we can't wait to hear how you’ll use the ScriptRunner Migration Suite to power your migrations!
