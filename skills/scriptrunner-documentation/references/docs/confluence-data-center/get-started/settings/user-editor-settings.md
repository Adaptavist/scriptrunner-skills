# User Editor Settings

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Get Started > Settings

The _User Editor_ setting allows you to enable or disable the editor minimap.

The [minimap](https://code.visualstudio.com/docs/getstarted/userinterface#_minimap) is visible on the right-hand side of your script. When you write a script, the minimap can be useful for navigating and understanding large areas of code. The minimap is enabled by default; you may wish to disable this feature if you don't find it useful.

## How to Enable/Disable

Note: Making a change to _User Editor Settings_ only impacts the current user. Each user can have their own preference.

1.  From ScriptRunner, navigate to the Settings page.
    
2.  Under User Editor Settings, toggle the Show Editor Minimap option on or off.
