# Create a Google Calendar Connector

- Platform: connect
- Space: SRC
- Hierarchy: Connectors
- Doc ID: doc-src-e11c5e82-04fd-4769-bb5f-023bd584c3ff-526e9b79a7e06225
- Source: https://docs.adaptavist.com/src/latest/connectors#create-a-google-calendar-connector--en

Follow these instructions to create a new connector for Google Calendar.

Making new connectors for Google apps is easy. In this example, we'll create a connector for Google Calendar. Follow these steps!

1.  Click Connectors on the left side of the page.
    
    The _Connectors_ module opens in the app.
    
2.  Click Create Connector.
    
    The _Create connector_ screen appears.
    
3.  Select the Google Calendar connector.
    
    The _Manage Connector_ dialogue appears.
    
4.  Enter a name for the connector, then click Sign In & Authorize With Google
    
    Sign in with your _Google account details_.
    
    The authorization wizard appears.
    
5.  Complete the authorization steps in the wizard.
    
    This includes a permissions prompt allowing ScriptRunner Connect to work with your selected app when accepted.
    
    Here's the example from the Google Calendar authorization, for which you should click Allow:
    
6.  Click Done from the _Manage Connector_ dialogue.
    
    A success message appears in the app, and your new Google Calendar connector is created.
    

Successfully set up connectors are given an _Authorized_ icon in the _Connectors_ screen.
