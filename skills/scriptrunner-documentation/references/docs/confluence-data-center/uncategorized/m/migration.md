This section provides you with the steps required to move between versions of ScriptRunner.

We cover the following migrations:

-   [Confluence Server to Cloud](https://docs.adaptavist.com/sr4c/latest/migration/migrating-to-or-from-cloud/migrate-from-scriptrunner-for-confluence-server-to-cloud)
-   [Confluence Cloud to Server](https://docs.adaptavist.com/sr4c/latest/migration/migrating-to-or-from-cloud/migrate-from-scriptrunner-for-confluence-cloud-to-server)
-   [Confluence Server to Confluence Data Center](https://docs.adaptavist.com/sr4c/latest/migration/migrating-to-data-center)

[Differences between the platforms](https://docs.adaptavist.com/sr4c/latest/migration/migrating-to-or-from-cloud/platform-differences) are highlighted for features and for framework, along with a [feature parity comparison](https://docs.adaptavist.com/sr4c/latest/migration/migrating-to-or-from-cloud/feature-parity). You can also find information about [GDPR Migration](https://docs.adaptavist.com/sr4c/latest/migration/migrating-to-or-from-cloud/gdpr-migration).
