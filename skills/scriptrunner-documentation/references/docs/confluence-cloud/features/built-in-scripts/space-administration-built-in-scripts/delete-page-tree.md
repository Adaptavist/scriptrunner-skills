# Delete Page Tree

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: features > built-in-scripts > space-administration-built-in-scripts
- Doc ID: doc-sr4cc-114204488
- Source: https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/space-administration-built-in-scripts/delete-page-tree

Using _Delete Page Tree_, you can delete a page tree (a page and all of its children). Deleted pages will be moved to the trash.

You must have _Edit_ permissions on all the pages you’re trying to delete.

## Run the script

To run this script, follow these steps: 

1.  Select a **Space.**
    
2.  Specify the page tree that you wish to delete in **Select a Space**. 
    
3.  Select **Run.**
