# Anonymous Analytics

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Get Started > Settings

_Anonymous Analytics_ collects ScriptRunner usage data, together with platform version, plugin version, and SEN, allowing Adaptavist to gain insight into ScriptRunner usage.

All data collected is for internal use only. See our [EULA](https://www.adaptavist.com/company/adaptavist-eula/) for more information.

_Anonymous Analytics_ is enabled by default (if Atlassian analytics is enabled).

To enable or disable _Anonymous Analytics_ follow the steps below:

1.  Navigate to the _Settings_ page by clicking any option from the administration Cog menu.
2.  Click ScriptRunner Settings under _ScriptRunner_ in the sidebar.
    
    CAUTION: Alternatively, if you are already on a ScriptRunner administration tab, click the Cog tab.
    
3.  Toggle Anonymous Analytics on/off.
    
    CAUTION: If Atlassian analytics is disabled, the toggle is greyed out. To check if Atlassian analytics is enabled, select Analytics under _Administration_ in the sidebar.
