You can create and manage personal credentials for scripts and integrations that use the ScriptRunner Migration Suite API.

## Navigate to API Keys

To get to API keys, select the next to your username, and then select API Keys.

## Create API Key

Follow these steps to create your API key, which will inherit your current access.

1.  Navigate to the _API Keys_ screen.
2.  Select +Create API Key.
3.  Enter a Key Name.
4.  Enter a time frame for Expires after. Your options are:
    
    -   _1 day_
    -   _30 days_
    -   _90 days_
    -   _180 days_
    -   _1 year_
    
5.  Select Create API Key.
6.  Copy your API key before you close the window.
7.  Store your key securely.
8.  Select Done.

You will now have to authenticate every request that uses that API key.

Your API key now shows up on the _API Keys_ page:

  
  

Select Revoke if your API key is ever exposed to delete it.
