# Workspaces

- Platform: connect
- Space: SRC
- Hierarchy: n/a

- Source: https://docs.adaptavist.com/src/latest/workspaces

The _Workspaces_ module is where all of your integrations live and run.

In the _Workspaces_ module, you can hold multiple scripts, API connections, and event listeners. It's also where you view your resource tree, the code editor (ScriptRunner Connect uses the Monaco code editor), and review console feedback.

Click **Workspaces** in the navigation panel to get started.
