# Show or Hide Enhanced Search Section Messages

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Get Started > Settings
- Doc ID: doc-sr4c-6aa1609f-2165-4eca-a329-26b52801fd89-d0d46f44dbd37f2e
- Source: https://docs.adaptavist.com/sr4c/latest/get-started#settings--en#show-or-hide-enhanced-search-section-messages--en

You can hide the [Enhanced Search](https://docs.adaptavist.com/sr4c/latest/features/enhanced-search) section messages.

Example shown here:

And here:

You can still use Enhanced Search, but the purple section messages will not be on the Search pages if you choose to hide the messages.

To show or hide the Enhanced Search messages, follow these steps:

1.  Navigate to the Settings page by clicking any option from the administration Cog menu.
2.  Click ScriptRunner Settings under ScriptRunner in the sidebar.
    
    Alternatively, if you are already on a ScriptRunner administration tab, click the Cog tab.
    
3.  Toggle Show Enhanced Search Section Messages on/off.
