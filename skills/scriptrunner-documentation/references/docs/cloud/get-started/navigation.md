To open ScriptRunner for Jira Cloud from within your Jira Cloud instance, click the Jira Administration **Cog** icon on the top right corner of your screen and select the **Apps** option.

You will see the ScriptRunner app menu appear within the left-hand sidebar navigation of your screen. Choose the _Browse_ option to get started using example scripts.

## Browse overview

The _Browse_ page provides you with a good starting point from which to understand the features that ScriptRunner for Jira Cloud offers. These features are represented by the four category icons that allow you to administer, automate, customise, and extend the functionality of Jira Cloud.

When you land on the _Browse_ page, you will see a welcome message and the script descriptions showing all categories of example scripts.

The _Browse_ page consists of four components:

1.  Search bar - use this free text field to search for keywords.
    
2.  Categories - select a category to view scripts filtered by one of the four functions.
    
3.  Filters - refine the results shown for a category or search using filters.
    
4.  Script descriptions - click the results to navigate to relevant script configuration pages.
    

![](/sr4jc/files/latest/126395920/524223751/2/1774290394000/srj-browse-page.png)

Each category is associated with example scripts that enable you to enhance efficiencies when working with Jira Cloud. You can find a specific script by using one of the following methods:

-   Choose any of the category icons depending on the task you want to perform, and a list of related script descriptions displays. 
-   Alternatively, use the _Browse_ page search function to discover scripts quickly. Enter keywords into the search bar to filter scripts by name or by goal, and the results display in the script descriptions list.

Regardless of the method used to find an example script, once results are displayed, you will see the associated filter icons. The filters enable you to further refine scripts by purpose or goal. You can click on any one of the script descriptions to open their corresponding configuration page.

Some categories appear greyed out, indicating that no example scripts are available for that particular category. We continuously strive to build on our examples, however, you can also check out the [Example scripts](https://www.scriptrunnerhq.com/help/example-scripts) library on our ScriptRunner HQ website.

## Browse example

This example aims to help you understand how the _Browse_ page functions. Let's take a scenario where a Jira administrator wants to reduce the amount of time spent on carrying out manual tasks by automating those tasks. In this case, an existing script can be accessed in ScriptRunner that helps to automate workflows in Jira Cloud. So, for example:

1.  Navigate to the _Browse_ page from the Jira _Administration_ menu by selecting **Apps > ScriptRunner > Browse**.  
2.  Select the **Automate c**ategory icon, or enter _Automate_ in the Search bar. Within the _Automate_ script description results that are displayed, you will see example scripts available under the _Perform actions_ filter, as highlighted below.
    
    ![](/sr4jc/files/latest/126395920/524223750/1/1774381436000/select-perform-acitons-filter.png)
    
      
    
3.  Select the **Perform actions** filter to see all associated automation scripts.
4.  Choose the relevant script and open the script configuration page.
