# Space Administration Built-In Scripts

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: features > built-in-scripts
- Doc ID: doc-sr4cc-114204332
- Source: https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/space-administration-built-in-scripts

Space administrators can: 

-   Make changes only on the spaces that they are admins of.
    
-   Access all features in the _ScriptRunner_ section.
    

Permissions

-   To restrict permissions take a look at our permissions documentation [here](https://docs.adaptavist.com/sr4cc/latest/get-started/settings).
-   To find out more about assigning space admin permissions, take a look at [Atlassian’s documentation](https://support.atlassian.com/confluence-cloud/docs/assign-space-permissions/).

## Navigation

1.  Navigate to your space. 
2.  Open **Space Settings** \> **Integrations** \> **ScriptRunner.**  
    The built-in scripts open:   
    ![](/sr4cc/files/latest/114204332/524223460/1/1774291878000/image.png)

Additionally, you can access the space administration built-in scripts from _Space apps_: 

![](/sr4cc/files/latest/114204332/524223461/1/1773943825000/2e21f1b5f04d6ee56acca9e05ebb472fe927af2c-296x482.png)

Keep in mind that you need admin or space admin permissions to view these built-in scripts.
