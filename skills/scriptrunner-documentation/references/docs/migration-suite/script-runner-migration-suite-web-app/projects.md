Projects contain all chats and analysis that you assign to them. You can share Projects within your organization or keep them private to you.

To see your projects or create a new one, navigate to Projects on the left-hand navigation:

## Create a project

1.  Select \+ Create Project in the upper right-hand corner of the _Projects_ page.
2.  Enter your Project Name.
3.  Select the Visibility. Your options are _Shared with organization_ or _Only me_. You can choose to share it later.
    
    Warning: You cannot share your Project with another organization.
    
4.  Select Create Project.

You will land on the specific project's Home Screen, with the title at the top:

Here, you can Share the project. You can also Edit (the name and visibility of the project) or Delete the project from the ellipses menu:

## Chats

Select Chats to see every chat you create within the project or assign to the project. You can also select Convert Script to Cloud to convert a single script.

Check out [Migration Agent](script-runner-migration-agent.md) for more information.

## Analysis Runs

Select Analysis runs to upload a zip file of your instance to analyze or to view all analysis related to the project. Check out the [Assess and Analyse Tool](script-runner-migration-analyse-and-assess-tool.md) for more information about what to find in an analysis.

Select See details to view the [data analyzed](script-runner-migration-analyse-and-assess-tool/use-the-analyse-and-assess-tool.md) for each instance.
