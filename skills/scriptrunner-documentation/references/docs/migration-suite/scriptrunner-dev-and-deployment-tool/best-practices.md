## Convert scripts

Use the [ScriptRunner Migration Agent](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-agent) to help convert scripts from Data Center to Cloud.

## Data Center instance analysis

Before you use the Dev and Deployment Tool, use the [ScriptRunner Migration Analyse and Assess Tool](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-analyse-and-assess-tool) to assess and analyse ScriptRunner Data Center scripts and configurations for risks and Cloud readiness.
