## How can I access an external REST API with ScriptRunner?

See our [example script](https://www.scriptrunnerhq.com/help/example-scripts/use-external-api-onPrem) that demonstrates this.

We also have an example of talking to the Git hub API which uses this [HTTP builder library](https://github.com/jgritman/httpbuilder/wiki).

With the above-mentioned HTTP builder library, you may also need to consult the [Authentication](https://github.com/jgritman/httpbuilder/wiki/Authentication) section depending on the requirements of the ThirdParty API.
