The following pages contain video courses and written tutorials to get you up and running with ScriptRunner for Jira Data Center or Server.

The [Introduction to ScriptRunner for Jira Data Center/Server](https://docs.adaptavist.com/sr4js/latest/training/course-introduction-to-scriptrunner-for-jira-data-center-server) course has equivalent written [tutorials](https://docs.adaptavist.com/sr4js/latest/training/tutorials) that cover the same topics, so the path you choose is up to you and how you like to learn.  The [Introduction to Scripting in ScriptRunner for Jira Data Center/Server](https://docs.adaptavist.com/sr4js/latest/training/course-introduction-to-scripting-in-scriptrunner-for-jira-data-center-server) course does not have a written equivalent and is in video format only.

You may also want to check out the [user documentation](https://docs.adaptavist.com/sr4js/latest/hapi) for HAPI.

HAPI is an API (application programming interface) we've developed for users to create automations and customizations faster than ever.
