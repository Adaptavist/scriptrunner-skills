# Coding Questions

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: scripting-resources
- Doc ID: doc-sr4cc-114205340
- Source: https://docs.adaptavist.com/sr4cc/latest/scripting-resources/coding-questions

You might come across some difficulties that could be because of a bug, or you could have configuration or coding question. Follow these steps to request help: 

Be sure to mention that you are using the Cloud version of ScriptRunner.

-   If it is a bug in the plugin, create an issue in the [Adaptavist Product Support Portal](https://productsupport.adaptavist.com/servicedesk/customer/portal/40/create/269). 
-   If it's a general configuration issue with the plugin, open a support request in the [Adaptavist Product Support Portal](https://productsupport.adaptavist.com/servicedesk/customer/portal/40/create/271)
-   If it's a coding question (like how to accomplish something with the API), ask a question on the [Atlassian Community](https://community.atlassian.com/t5/tag/addon-com.onresolve.confluence.groovy.groovyrunner/tg-p). 
    
    Community is the widest audience, so this is the best shot of answering your specific coding question. Mention that you're using the ScriptRunner add-on.
