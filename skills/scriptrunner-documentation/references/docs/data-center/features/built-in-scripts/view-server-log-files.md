# View Server Log Files

- Platform: data-center
- Space: SR4JS
- Hierarchy: features > built-in-scripts
- Doc ID: doc-sr4js-441364375
- Source: https://docs.adaptavist.com/sr4js/latest/features/built-in-scripts/view-server-log-files

Use _View Server Log Files_ to show the last N lines of application log files. Follow these steps to run the built-in script:

1.  Navigate to **Built-in Scripts>View Server Log Files**.
2.  Select the log file to view in **Log File**.
    
3.  Enter the number of lines to display in **Number of Lines**. The script returns the last N number of lines from the log file.
    
4.  Click **Run** to view the results.
    
    You can select **Preview** instead of **Run** to view changes before implementing them.
    
    Once you select **Run**, the _Results_ of the script appear.
    

![Image of the results](/sr4js/files/latest/441364375/441364378/1/1737998733000/view-server-log-files.png)

Increase the logging level to help debug scripts. See [logging levels](https://docs.adaptavist.com/sr4js/latest/best-practices/logging/advanced-logging#id-.AdvancedLoggingv9.x-loglevels) for more information.

For information on more advanced logging in ScriptRunner see [Advanced Logging](https://docs.adaptavist.com/sr4js/latest/best-practices/logging/advanced-logging).
