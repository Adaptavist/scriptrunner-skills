You can install ScriptRunner for Jira as follows:

Note: To find more information and purchase ScriptRunner for Jira, visit the [Atlassian Marketplace](https://marketplace.atlassian.com/apps/6820/scriptrunner-for-jira?hosting=datacenter&tab=overview).

1.  Log into your Jira instance as an administrator.
2.  From the Administration drop-down, select Manage apps.
    
    The Atlassian Marketplace for Jira screen loads.
    
3.  Use the search function to find ScriptRunner for Jira.
    
    Tip: You can look through our [version history page](https://marketplace.atlassian.com/apps/6820/scriptrunner-for-jira/version-history) to find older ScriptRunner for Jira versions compatible with your instance. The Atlassian documentation on [Installing Marketplace Apps](https://confluence.atlassian.com/upm/installing-marketplace-apps-273875715.html) details how to install an app from a file–these instructions are required if you need to install an older version of your choice.
    
4.  Select one of the following:
    
    -   Free trial to begin a new trial.
    -   Buy now to purchase a license for ScriptRunner for Jira.
    
    Note: Check out the [Atlassian Marketplace listing](https://marketplace.atlassian.com/apps/6820/scriptrunner-for-jira?tab=pricing&hosting=datacenter) for more details on pricing and the free trial.
    
5.  On the Confirm app installation screen check you're happy with the privacy policy and terms of use, then select Accept & install.
    
    Depending on your choice in step 4, you'll be redirected to either generate a trial license or purchase a Data Center license.
    
6.  Your license can be applied automatically, or you can copy and paste the license into your Jira instance on the Manage Apps page.
    

## Plugin upload in Jira

The plugin upload from the UI ( _upload app_ link) is disabled by default on Jira versions equal to or higher than [9.4.17](https://jira.atlassian.com/issues/?jql=project+%3D+JRASERVER+AND+fixVersion+%3D+9.4.17), [9.12.4](https://jira.atlassian.com/issues/?jql=project+%3D+JRASERVER+AND+fixVersion+%3D+9.12.4), [9.14.0](https://jira.atlassian.com/issues/?jql=project+%3D+JRASERVER+AND+fixVersion+%3D+9.14.0), or any other Jira version with Universal Plugin Manager 6.1.9 or higher. Check out Atlassian documentation if you want to [re-enable plugin upload in Jira Data Center](https://confluence.atlassian.com/jirakb/how-to-re-enable-plugin-upload-in-jira-data-center-1364557898.html).
