# Space Administration Built-In Scripts

- Platform: confluence-cloud

Learn about the built-in scripts related to Space administration tasks.

Space administrators can:

-   Make changes only on the spaces that they are admins of.
-   Access all features in the _ScriptRunner_ section.

Note: Permissions

-   To restrict permissions take a look at our permissions documentation [here](../../get-started/settings.md).
-   To find out more about assigning space admin permissions, take a look at [Atlassian's documentation](https://support.atlassian.com/confluence-cloud/docs/assign-space-permissions/).
