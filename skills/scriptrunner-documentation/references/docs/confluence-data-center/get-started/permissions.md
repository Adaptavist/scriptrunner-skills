# Permissions

- Platform: confluence-data-center

You must have administrator rights to use ScriptRunner for Confluence. Use our table to know which permissions you need for each feature.

For more information each type of permissions, please visit [Atlassian's Global Permissions Overview](https://confluence.atlassian.com/doc/global-permissions-overview-138709.html#GlobalPermissionsOverview).
