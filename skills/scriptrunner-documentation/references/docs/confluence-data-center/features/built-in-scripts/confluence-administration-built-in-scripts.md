Information about and instructions for our Built-In Scripts for Confluence Administration.

To access these built-in scripts, follow these steps:

1.  Select the Confluence Administration cog, and then select General Configuration.
2.  Select Built-In Scripts from the _ScriptRunner_ section on the left-hand side of the screen.

The following scripts are for administrator use:
