## Feature navigation

In General Configuration, ScriptRunner options appear in the left-hand navigation.

Once you select a feature, it appears on the screen. The remaining features are displayed in a toolbar at the top of the screen.

## ScriptRunner Home

Each admin has access to the ScriptRunner Home page, where you can explore features in ScriptRunner that you want to learn more about. The ScriptRunner Home page is particularly helpful for onboarding.

### Navigate to Home

There are 2 methods of accessing the Home page:

-   Get to Home from any page of ScriptRunner for Confluence by clicking Home from the ScriptRunner menu options.
-   Use the Home tab in the ScriptRunner administration toolbar.

### Home page main features

There are three main sections on the Home page to help you navigate and learn ScriptRunner for Confluence.

#### Audit

Use features in the Audit section to gain insight into your instance. You can view the jobs that are running, identify structural issues, and understand usage trends.

#### Clean-up

Use features in this section to ensure the performance of your instance. You can improve user results by automatically removing outdated content.

#### Optimize

Use features in this section to tailor Confluence to your needs. You can manage spaces and contributors, ensure robust links, and enhance content.

### Additional Home page functionality

#### Latest Errors

Find the _Latest Errors_ section below the three main options. This log displays the latest errors generated by your scripts in the app.

You can gain an overview or click a specific script to drill into the problem.

#### Help

Find support links at the bottom of the page to help get you the information you need.

## Quick Scripting

Use the Quick Scripting page to search and discover ScriptRunner functionality, including scripts and macros.

Access Quick Scripting from the option in the top right section of the _Home_ page.

Note: Browse

Quick Scripting was previously titled Browse.

Quick Scripting consists of three main sections:

-   Search: You can search your scripts here. This is a free-text field, so you can search for any keyword. Your keyword is highlighted in search results.
-   Categories: You can select a category to constrain search results. Your categories are:
    -   Organize Your Content
    -   Manage Your Storage
    -   Diagnose & Solve Issues
    -   Customize & Automate
-   Script Descriptions: This is where your search results are. The keyword and categories are noted here.
    
    You can select a script from this page, such as Bulk Delete Attachments, to navigate to it.
