# Built-In Scripts

ScriptRunner built-in scripts are out-of the-box solutions, created by us, made to help you get started customizing, automating, and extending Confluence to suit your needs.

Leverage our built-in scripts to automate manual, complex, and time-consuming tasks. Aimed at users with limited Groovy knowledge, built-in scripts allow you to quickly achieve your goals without having to write Groovy code from scratch.

Note: All built-in scripts are always visible and executable by users with Jira Administration and Jira System Administration permissions.

There are two types of built-in scripts, meant for different types of administrators:

-   [Confluence Administration Built-In Scripts](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/confluence-administration-built-in-scripts)
-   [Space Administration Built-In Scripts](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/space-administration-built-in-scripts)

## Permissions

You must have administrator rights to use ScriptRunner for Confluence built-in scripts. For more information on each permission type, please visit [Atlassian's Global Permissions Overview](https://confluence.atlassian.com/doc/global-permissions-overview-138709.html#GlobalPermissionsOverview).

Administrators will find helpful information on permissions in our [Settings](https://docs.adaptavist.com/sr4c/latest/get-started/settings) section of our documentation.

## Examples

Built-in scripts have been created for some of the most commonly run tasks in ScriptRunner. For example, we have scripts to:

-   Use the [Manage Labels](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/confluence-administration-built-in-scripts/manage-labels) script to rename, add, and remove page labels in bulk.
-   Make a complete copy of an existing space using [Copy Space](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/confluence-administration-built-in-scripts/copy-space).
-   [Switch User](https://docs.adaptavist.com/sr4c/latest/features/built-in-scripts/confluence-administration-built-in-scripts/switch-to-a-different-user) to complete tasks as a different user.
-   Show all configured ScriptRunner scripts on your instance with the [Script Registry](https://docs.adaptavist.com/sr4c/latest/features/script-registry).

## Browse Built-in Scripts functionality

You can use the Search ScriptRunner Functionality search bar to search the available built-in scripts.

For example, if you're looking for a built-in script that works with restrictions, you could type Restrictions and press Enter. Then, the list of built-in scripts is narrowed to those that contain the word "restrictions" in their title or description.
