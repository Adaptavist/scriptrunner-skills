# Installation

- Platform: confluence-cloud
- Space: SR4CC
- Hierarchy: get-started
- Doc ID: doc-sr4cc-114204871
- Source: https://docs.adaptavist.com/sr4cc/latest/get-started/installation

To find more information and purchase ScriptRunner for Confluence, visit the [Atlassian Marketplace](https://marketplace.atlassian.com/apps/1215215/scriptrunner-for-confluence?hosting=cloud&tab=overview). 

To install ScriptRunner for Confluence Cloud, follow these steps: 

1.  Log into your Confluence Cloud instance as an admin.
2.  Select the **Cog** in the upper right-hand corner of the screen.
3.  Click **Find new apps** from the left-hand side of the page.
4.  Locate **ScriptRunner for Confluence Cloud** via search.  
    The appropriate app version appears in the search results. 
5.  Click **Try free** to begin a new trial or **Buy now** to purchase a license for **ScriptRunner for Confluence Cloud**.  
    You're prompted to log into MyAtlassian. ScriptRunner for Confluence Cloud begins to download. 
6.  Enter your information and click **Generate license** when redirected to MyAtlassian.
7.  Click **Apply license**.  
    If you're using an older version of UPM, you can copy and paste the license into your Confluence instance.
8.  Once ScriptRunner for Confluence Cloud has finished installation, click **Get Started**.
