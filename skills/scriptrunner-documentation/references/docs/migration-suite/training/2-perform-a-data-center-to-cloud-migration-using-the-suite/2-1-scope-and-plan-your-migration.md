# 2.1 Scope and plan your migration

- Platform: migration-suite
- Space: SMS
- Hierarchy: Training > 2. Perform a Data Center to Cloud migration using the suite
- Doc ID: doc-sms-34f9c3ac-71d3-4bb4-aeef-009c5aa1e709-1c28e089679b0f9d

Until now, manually scoping a migration has been a time-consuming process. However, it's a critical step in the migration process that enables our teams to determine the complexity of a migration and avoid surprises.

The Analyse tool streamlines this process by analysing uploaded scripts and configurations, assessing their Cloud readiness, then providing a high-level report of the migration work required. Additionally, we can delve further into this analysis to obtain deeper insights and determine necessary actions.

Note: Wondering how to get Data Center scripts into the ScriptRunner Migration Suite for analysis?

We recommend using the ScriptRunner for Jira DC Export Button. For further details, see the [Script Registry](https://docs.adaptavist.com/sr4js/latest/features/script-registry) documentation.
