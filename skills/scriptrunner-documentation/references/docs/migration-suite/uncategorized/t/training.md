### Introduction

Welcome! This short course is designed to ensure you get the most out of the **ScriptRunner Migration Suite**, a powerful set of tools built to bring order to complex migrations and accelerate your move to the Cloud.

By the end of this course, we hope you’ll not only recognise the key migration challenges the ScriptRunner Migration Suite can help you overcome—beyond the use cases we’ve presented—but also feel equipped and excited to use the tools to support your own migration to Cloud, wherever you are in your journey.

  

### Course structure

This course is divided into two key sections:

1.  **Meet the ScriptRunner Migration Suite**
    
2.  **Perform a Data Center to Cloud Migration using the ScriptRunner Migration Suite**
    

  

In the first section, **Meet the ScriptRunner Migration Suite**, you'll discover the tools included in the suite and some of the common migration challenges it has been designed to help your team overcome. In the second, we'll guide you through using ScriptRunner Migration Suite to carry out your first Data Center to Cloud migration.
