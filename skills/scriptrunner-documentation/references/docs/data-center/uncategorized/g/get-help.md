## Support Requests

Please contact [Adaptavist Support](https://the-adaptavist-group-support.atlassian.net/servicedesk/customer/portal/21) if:

-   you find what appears to be a bug in ScriptRunner.
-   you have a general configuration issue with ScriptRunner.

When contacting Adaptavist Support, please include the following information:

-   ScriptRunner SEN
-   ScriptRunner version
-   Jira version
-   Support Zip (please enable ScriptRunner logging following the [Logging Levels instructions](https://docs.adaptavist.com/sr4js/latest/best-practices/logging/advanced-logging))

Tip: For information on how to create a support zip see the Atlassian [Create a Support Zip](https://confluence.atlassian.com/support/create-a-support-zip-790796819.html) documentation.

## Find Your Support ID Number

When contacting The Adaptavist Group (TAG) Support, you must provide your Entitlement ID (SEID) or your License SEN so we can provide you with the best possible service.

Cloud customers: If you have a cloud product, you must provide your Entitlement ID.

DC customers: If you have a Data Center product, you must provide your SEN.

You can find your Entitlement ID or SEN using one of the following methods:

### Find Your SEN in an Atlassian Data Center Product

1.  From your Atlassian product, click the Jira Administration cog in the top-right corner, and select Manage apps.
2.  Scroll to find your Adaptavist app and click the expand caret to get more information.

This provides you with the SEN, as well as other details about the app.

## Jira Version

To find your Jira version, navigate to Applications from the _Jira Administration Menu_.

Tip: The version number is also visible in your Jira footer.
