# Bulk Clone Work Items

- Platform: cloud
- Space: SR4JC
- Hierarchy: features > built-in-scripts
- Doc ID: doc-sr4jc-101628965
- Source: https://docs.adaptavist.com/sr4jc/latest/features/built-in-scripts/bulk-clone-work-items

You can select Jira work items to clone and move to another space as a set of work items in bulk. To do so:

1.  Navigate to the _Bulk clone work items_ page from the Jira _Administration_ menu by selecting **Apps > ScriptRunner > Built-in Scripts**.
2.  Enter the **Subquery (JQL)** for the work items you want to clone.
3.  Select the space you want the cloned work items to move to from the **Space** drop-down list.
4.  Click the **Run** button, or click **Choose another script** to repeat the process and clone more work items.

![](/sr4jc/files/latest/101628965/523764285/1/1774005491000/bulk+clone+work+items.png)

You can clone up to 50 work items, or search for work items in groups in the JQL.
