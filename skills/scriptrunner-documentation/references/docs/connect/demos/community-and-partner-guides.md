Explore curated guides, deep dives, and tutorials created by the ScriptRunner team and community partners.

These articles cover everything from setting up local development environments and mastering REST APIs to architectural integration patterns and real-world orchestration recipes.

## 💻 External coding and local development

Learn how to build, test, and maintain ScriptRunner Connect workspaces locally using your favorite tools, IDEs, and AI assistants.

-   [External Coding Series 1: Your IDE, Your Rules](https://www.ambientia.fi/en/news/scriptrunner-connect-external-coding-series-1-your-ide-your-rules) - A guide to setting up local development environments, managing workspace file structures, and leveraging standard developer tooling alongside ScriptRunner Connect.
    
-   [External Coding Series 2: Testing Without Tears](https://www.ambientia.fi/en/news/scriptrunner-connect-external-coding-series-2-testing-without-tears) - Best practices for structuring unit tests, mocking external API calls, and verifying integration logic before deploying to production.
    
-   [External Coding Series 3: API Magic](https://www.ambientia.fi/en/news/scriptrunner-connect-external-coding-series-3-api-magic) - Techniques for working with external APIs during local development, including payload inspection and managing environment variables.
    
-   [External Coding Series 4: AI-Powered Development](https://www.ambientia.fi/en/news/scriptrunner-connect-external-coding-series-4-ai-powered-development) - How to integrate AI coding assistants (such as GitHub Copilot and ChatGPT) into your ScriptRunner Connect development workflow.
    

## 🔌 APIs and managed connectors

Master the fundamentals of REST APIs and discover how managed connectors simplify third-party authentication and API interactions.

-   [Getting to Grips with the Basics of REST APIs](https://www.scriptrunnerhq.com/inspiration/resources/tutorials/getting-to-grips-with-the-basics-of-rest-apis) - A foundational primer explaining HTTP methods, headers, query parameters, status codes, and JSON payloads.
    
-   [REST APIs Made Easy with ScriptRunner Connect](https://www.scriptrunnerhq.com/inspiration/resources/tutorials/rest-apis-made-easy-with-scriptrunner-connect) - An introduction to making API calls using ScriptRunner Connect's built-in client libraries and authentication helpers.
    
-   [Building a Managed API](https://www.scriptrunnerhq.com/inspiration/resources/tutorials/building-a-managed-api) - Step-by-step instructions for defining endpoints, configuring parameter types, and packaging custom managed API definitions.
    
-   [Simplify Your Atlassian Integrations: How Generic Connectors Reduce Costs and Complexity](https://www.ambientia.fi/en/news/simplify-your-atlassian-integrations-how-generic-connector-reduces-costs-and-complexity) - How to connect to unsupported or bespoke REST APIs without needing custom-built connector packages.
    

## 🏛️ Architecture, security, and integration patterns

Design resilient, scalable, and secure integrations while avoiding common traps in event-driven systems.

-   [How to Connect Anything to Everything: A Journey Through APIs and Managed Solutions](https://www.ambientia.fi/en/news/how-to-connect-anything-to-everything-a-journey-through-apis-and-managed-solutions) - An architectural overview of modern integration strategies, comparing point-to-point connections against managed platforms.
    
-   [Atlassian Service Accounts vs. API Tokens: Why the Switch is Harder Than You Think](https://www.ambientia.fi/en/news/atlassian-service-accounts-vs.-api-tokens-why-the-switch-is-harder-than-you-think) - A deep dive into Atlassian cloud authentication, evaluating the migration path, permissions, and security trade-offs of Service Accounts.
    
-   [The Infinite Loop Trap: How to Prevent Your Integration from Talking to Itself](https://www.ambientia.fi/en/news/the-infinite-loop-trap-how-to-prevent-your-integration-from-talking-to-itself) - How to identify and avoid event feedback loops when triggers and webhooks listen to updates made by the integration itself.

Real-world scenarios demonstrating multi-system orchestration and event handling in practice.
