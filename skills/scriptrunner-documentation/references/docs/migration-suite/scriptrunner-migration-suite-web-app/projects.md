# Projects

- Space: SMS
- Hierarchy: scriptrunner-migration-suite-web-app

Projects contain all chats and analysis that you assign to them. You can share Projects within your organization or keep them private to you.

To see your projects or create a new one, navigate to **Projects** on the left-hand navigation:

![](/sms/files/latest/566298718/585009412/1/1787597370000/projects-home.png)

## Create a project 

1.  Select **\+ Create Project** in the upper right-hand corner of the _Projects_ page.
2.  Enter your **Project Name**.
3.  Select the **Visibility**.  
    Your options are _Shared with organization_ or _Only me_. You can choose to share it later.  
    
    You cannot share your Project with another organization.
    
4.  Select **Create Project**.

You will land on the specific project's Home Screen, with the title at the top: 

![](/sms/files/latest/566298718/585009414/1/1787597548000/new-project.png)

Here, you can **Share** the project. You can also **Edit** (the name and visibility of the project) or **Delete** the project from the ellipses menu:

![](/sms/files/latest/566298718/566298746/1/1784146121000/ellipses+menu.png)

## Chats

Select **Chats** to see every chat you create within the project or assign to the project. You can also select **Convert Script to Cloud** to convert a single script.

![](/sms/files/latest/566298718/585009415/2/1787597771000/project-chats.png)

Check out [Migration Agent](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-agent) for more information. 

## Analysis Runs

Select **Analysis runs** to upload a zip file of your instance to analyze or to view all analysis related to the project. Check out the [Assess and Analyse Tool](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-analyse-and-assess-tool) for more information about what to find in an analysis.

![](/sms/files/latest/566298718/585009417/1/1787597772000/projects-analysis.png)

Select **See details** to view the [data analyzed](https://docs.adaptavist.com/sms/latest/scriptrunner-migration-suite-web-app/scriptrunner-migration-analyse-and-assess-tool/use-the-analyse-and-assess-tool) for each instance.
