Using _Space Statistics_, you get an overview of your Confluence spaces.

You can see the following statistics:

-   Number of attachments
-   Number of pages
-   Number of blogs
-   Number of comments
-   Number of labels
-   Number of likes
-   Number of trash
-   Creation date

## Run the script

To use this built-in script, follow these steps:

1.  Select Space Tools from the bottom left-hand corner of the screen.
2.  Select Advanced Space Functionality.
3.  Select Space Statistics.
4.  Select the space you want to work with in Spaces.
    
5.  Select Run.
    
    Tip: You can select Preview instead of Run to view changes before implementing them.
