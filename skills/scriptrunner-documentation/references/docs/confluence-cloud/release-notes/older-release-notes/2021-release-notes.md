## November 2021

### New Custom Macro Feature

A [Custom Macro](https://docs.adaptavist.com/sr4cc/latest/features/macros/custom-macros) feature has been added to ScriptRunner for Confluence Cloud! Using custom macros, you can write your own static content macros. To see this macro in use, check out [Example: Stock Exchange Price](https://docs.adaptavist.com/sr4cc/latest/features/macros/custom-macros/example-stock-exchange-price).

## October 2021

### **Macro Migration  
**

When you migrate from ScriptRunner for Confluence Server or Data Center to ScriptRunner for Confluence Cloud, macros are unsupported and need to be replaced with a supported Cloud macro. [Macro Migration Tips](https://docs.adaptavist.com/sr4cc/latest/migration/feature-parity/macro-migration-tips) has step-by-step instructions for migrating your existing _Add Label_, _Choose Label_, and _Page Info_ macros. 

### **Space Administration Navigation Change**

The space administration scripts navigation has changed. Check [Space Administration Built-In Scripts](https://docs.adaptavist.com/sr4cc/latest/features/built-in-scripts/space-administration-built-in-scripts) for more information.
