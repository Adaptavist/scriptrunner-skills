# Rate Limits

- Platform: cloud
- Space: SR4JC
- Hierarchy: features > scriptrunner-enhanced-search > troubleshoot-scriptrunner-enhanced-search
- Doc ID: doc-sr4jc-513345637
- Source: https://docs.adaptavist.com/sr4jc/latest/features/scriptrunner-enhanced-search/troubleshoot-scriptrunner-enhanced-search/rate-limits

Atlassian limits the rate of REST API requests to ensure that services are reliable and responsive for all customers. This means that the number of API requests your app or integration can make to Jira Cloud within a given time period is subject to rate-limiting controls.

You can find more information about Atlassian’s rate limiting approach and guidance [here](https://developer.atlassian.com/cloud/jira/platform/rate-limiting/). We have designed our services to handle API usage with Atlassian’s rate-limiting guidance in mind.
