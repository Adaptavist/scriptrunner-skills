# Built-In Script Fields

- Platform: data-center
- Space: SR4JS
- Hierarchy: features > script-fields
- Doc ID: doc-sr4js-101624078
- Source: https://docs.adaptavist.com/sr4js/latest/features/script-fields/built-in-script-fields

As part of the ScriptRunner framework, there are provided built-in scripts that you can use. These save time on common scripted fields because you need to write little or no code to implement them.

### Creating a new built-in scripted field

1.  Navigate to the Script Fields Screen.
    
2.  Click the "Add New Item" button (see screenshot below) to see a list of built-in script fields available.
    
    ![](/sr4js/files/latest/101624078/101627762/1/1600769236000/csf_add_new_item+%281%29.png)
3.  Select the field you wish to create by left-clicking on it.
    
    ![](/sr4js/files/latest/101624078/101627741/1/1600769237000/csf_select_field.png)
4.  Fill in the form with the parameters that you require for the selected field.
    
    You can click "Preview" to run the script and check the value that your field will output.
    
5.  Click the "Add" button to add the field to your instance.
    
    You’ll now notice that your new field should appear in the list on the Script Fields Screen.
    
6.  You should now configure the following:
    1.  The screens that you would like to see the field in
    2.  The context that you would like the field to be available for

These are linked from both the the fields configuration menu. You will also see a warning when you first add the field linking you to these configurations (see screenshot below).

![](/sr4js/files/latest/101624078/101627742/1/1600769237000/csf_add_warning.png)
