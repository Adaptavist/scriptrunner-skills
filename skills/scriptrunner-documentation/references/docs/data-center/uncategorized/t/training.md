The following pages contain video courses and written tutorials to get you up and running with ScriptRunner for Jira Data Center or Server.

The [Introduction to ScriptRunner for Jira Data Center](../../training/course-introduction-to-script-runner-for-jira-data-center.md) course has equivalent written [tutorials](../../training/tutorials.md) that cover the same topics, so the path you choose is up to you and how you like to learn. The [Introduction to Scripting in ScriptRunner for Jira Data Center](../../training/course-introduction-to-script-runner-for-jira-data-center.md) course does not have a written equivalent and is in video format only.

Note: You may also want to check out the [user documentation](../h/hapi.md) for HAPI.

HAPI is an API (application programming interface) we've developed for users to create automations and customizations faster than ever.
