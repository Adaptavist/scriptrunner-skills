# Event Listeners

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Features
- Doc ID: doc-sr4c-6f061b4d-072e-476e-9927-ac17974c044d-894ebcf5f033b3ee
- Source: https://docs.adaptavist.com/sr4c/latest/features#event-listeners--en

ScriptRunner allows you to respond to Confluence events via an inline script or a pointer to a file. These responses are called event listeners.

Example event listeners follow:

-   Ensuring a Jira project exists for a corresponding Confluence space
-   Sending an email when a space is deleted
-   Set up a publishing process for new spaces

Warning: When you opt to Add Examples for listeners and select _Send notifications when a page label is added_, you need a mail server configured. If a mail server is not configured, you will get an error.
