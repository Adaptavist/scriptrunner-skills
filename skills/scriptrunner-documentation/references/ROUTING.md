# Routing Guide

Use this file first to route to the smallest useful set of docs.

## Platform routing

- For ScriptRunner for Jira Cloud, Jira Cloud HAPI, Forge, or Jira Cloud REST integrations, start with Cloud docs.
- For ScriptRunner for Confluence Cloud, Confluence HAPI, Confluence listeners, CQL jobs, spaces, pages, or custom macros, start with Confluence Cloud docs.
- For ScriptRunner Connect apps, connectors, recipes, webhooks, or remote integrations, start with ScriptRunner Connect docs.
- For Jira Data Center, Data Center HAPI, Atlassian Java APIs, or on-prem administration, start with Data Center docs.
- For ScriptRunner Migration Suite web app, migration-agent, assess/analyse, or Dev and Deployment Tool questions, start with ScriptRunner Migration Suite docs.
- If the platform or product is unclear, compare the relevant indexes before opening page content.

## Topic routing

- Setup and configuration: search for installation, app settings, authentication, and permissions.
- Script authoring: search for feature-specific pages before drafting code.
- Migrations: prioritize pages that describe Cloud vs ScriptRunner Connect vs Data Center differences.
- Migration Suite workflows: use ScriptRunner Migration Suite docs for SMS UI behaviour, migration-agent guidance, analyse/assess usage, and Dev and Deployment Tool YAML/deployment docs.
- REST integrations: use documentation pages for ScriptRunner behavior and the `atlassian-cloud-rest-api` skill for Atlassian REST details.

## Progressive disclosure order

1. Read the relevant platform index.
2. Open 1-3 matching pages under `references/docs/...`.
3. Expand only when those pages do not answer the question.
