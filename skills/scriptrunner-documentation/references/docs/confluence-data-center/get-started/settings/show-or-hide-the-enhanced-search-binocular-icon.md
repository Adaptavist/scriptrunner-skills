# Show or Hide the Enhanced Search Binocular Icon

- Platform: confluence-data-center
- Space: SR4C
- Hierarchy: Get Started > Settings
- Doc ID: doc-sr4c-cba54ba1-6a33-4a77-b011-0411d9fe2387-627b5102f89f44bd
- Source: https://docs.adaptavist.com/sr4c/latest/get-started#settings--en#show-or-hide-the-enhanced-search-binocular-icon--en

You can now hide the binoculars icon for [Enhanced Search](https://docs.adaptavist.com/sr4c/latest/features/enhanced-search) for all users in the instance.

Note: If you choose to hide the icon, the page can still be accessed with a direct link.

To show or hide the icon, follow these steps:

1.  Navigate to the Settings page by clicking any option from the administration Cog menu.
2.  Click ScriptRunner Settings under ScriptRunner in the sidebar.
    
    Note: Alternatively, if you are already on a ScriptRunner administration tab, click the Cog tab.
    
3.  Toggle Show Enhanced Search Binocular icon on/off.
